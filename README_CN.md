# ComfyUI-CatNodes

<p align="center"><strong>中文</strong> ·<a href="README.md">English</a></p>

ComfyUI-CatNodes 是一个 ComfyUI 扩展，提供七个工作流节点和四项界面功能：菜单栏实时系统状态、ComfyUI 内嵌的无限画布、用于浏览磁盘文件的媒体资产面板，以及可选的多用户文件隔离。

界面文案跟随 ComfyUI 的语言设置（中文 / 英文）。无需额外安装 Python 依赖，画布所需内容已全部包含。

## 快速开始

### 安装

1. 将 `ComfyUI-CatNodes` 文件夹放入 `ComfyUI/custom_nodes/`。
2. 重启 ComfyUI。

ComfyUI 启动后即可使用状态栏和画布，无需在流程中添加任何节点。进入画布的方式有三种：按 `Ctrl+Shift+I`，选择菜单 **View → 打开 / 退出无限画布**，或点击状态栏最左侧的画布按钮。

### 环境要求

- 使用带 `comfy_api` 的 ComfyUI 版本（节点基于 V3 节点接口）。
- 系统状态中的 GPU、显存、温度读数以及文件缓存清理需要 Windows；其他系统上这些项显示 `N/A` 或跳过该步骤。
- 无额外 Python 依赖。

### 卸载

删除 `custom_nodes/ComfyUI-CatNodes/` 文件夹，重启 ComfyUI。

## 界面功能

### 菜单栏系统状态

ComfyUI 启动后，菜单栏出现状态区，显示五项读数，每 0.5 秒刷新一次。将鼠标悬停在任一读数上可查看详情。

| 指标 | 区内文字 | 悬停信息 |
| --- | --- | --- |
| CPU | 占用百分比 | 占用百分比 |
| RAM | 占用百分比 | 占用百分比、已用/总内存 |
| GPU | 占用百分比 | 占用百分比、显卡型号 |
| VRAM | 已用显存（GB） | 占用百分比、已用/总显存、本次会话峰值 |
| 温度 | 当前温度（°C） | 当前温度、显卡型号、40–85 °C 区间内的相对位置 |

未检测到 NVIDIA 显卡时，GPU、VRAM、温度显示 `N/A`，CPU 与 RAM 不受影响。温度填充色在 40 °C 至 85 °C 之间由绿变红。

状态段左侧从左到右依次是：画布按钮、「导入到画布」、分隔符、RAM 清理按钮与 VRAM 清理按钮。

- 「导入到画布」把当前工作流导入画布。
- 「RAM 清理」与「VRAM 清理」点击后直接把对应的清理节点排入队列，无需自己在流程中添加节点。

### 无限画布

画布是与工作流平级的一种模式。随时可用 `Ctrl+Shift+I`、菜单 **View → 打开 / 退出无限画布** 或状态栏画布按钮进入和退出。画布内容按用户保存，返回时自动恢复。节点与媒体都存在于画布上，工作流不受影响。图片、视频和音频可直接在画布上播放。

画布语言跟随 ComfyUI 的语言设置，没有独立的语言切换。

### 媒体资产

媒体资产**位于无限画布内部**，ComfyUI 主界面没有单独的标签页。进入画布后，从画布侧栏的「媒体资产」入口打开，面板在画布抽屉中显示。它列出当前账号 `output/` 与 `input/` 目录中磁盘上实际存在的全部文件，不限于本次会话产生的文件。单用户启动时读取全局的 `input/` 与 `output/` 目录。

| 区域 | 内容 |
| --- | --- |
| 分页 | 已生成（output）、已导入（input） |
| 类型筛选 | 全部、文本、图像、视频、音频、其他 |
| 工具栏 | 存放文件夹选择、文件名搜索、刷新、视图切换（列表、网格小、网格大） |
| 卡片信息 | 文件名、大小、修改时间 |

- 单击选中，Ctrl 单击加选，Shift 单击连选，空白处拖动框选。
- 选中文件后显示浮动操作条，含选中数量、「全部下载」「全部删除」「取消全选」。
- 右键菜单：「查看资产」「下载」「删除」；双击卡片也可打开查看。预览层中视频与音频可直接播放，文本显示内容开头，可打开原文件或下载。
- 「删除」把文件移动到系统回收站，可在资源管理器中还原；不支持回收站的位置（如网络驱动器）上直接删除。文件被占用时保留在原处并显示删除失败提示。

### 多用户文件隔离

仅在以 `--multi-user` 启动 ComfyUI 时生效，普通单用户启动不受影响。

- `input/` 与 `output/` 按账号分为 `input/<用户>/` 与 `output/<用户>/`，各账号的上传与生成文件互不可见。
- 历史、队列、任务列表按账号隔离。
- 登录使用 ComfyUI 原生的用户选择流程，不设额外密码。
- 全局 `input/`、`output/` 中的既有文件对所有账号不显示。

## 节点

### 清理显存 🐈‍⬛

按需释放显存。每次提交队列都会重新执行，无需重复添加。可选的 `anything` 输入原样返回，可把节点串进执行链。详情写入 ComfyUI 日志，没有文本输出。

### 回收内存 🐈‍⬛

默认在当前提示词执行后清理 ComfyUI 自身的执行缓存，保留已加载的模型。同样每次提交队列都会重新执行，可选的 `anything` 输入原样返回。

唯一选项「清理文件缓存」改为重置 Windows 系统文件缓存。该操作影响整个系统，需要管理员权限；权限不足时可能静默无效。此选项仅 Windows 有效。

### 任意切换 🐈‍⬛

从多路输入中只转发一路的开关。可同时接入多路分支输出；首次连线决定所有端口与输出的类型。端口随连接增长，上限 9 个。运行时仅转发携带数据的一路，无输入或多路同时有数据时报错。切换分支在上游完成，下游无需重新连线。

### 组控制 🐈‍⬛

以分组为单位开关画布内容。面板位于节点内部，每个非空分组占一行，行内为分组名称与开关。完全位于某分组内部的子分组也会列出；空分组不列出。关闭一行时把组内全部节点设为「绕过」或「禁用」。`signal` 为透传输入，不参与切换。

### 节点控制 🐈‍⬛

使用同一面板，粒度为单个节点。便签、Reroute、PrimitiveNode 及本节点自身被排除。关闭一行时把该节点设为「绕过」或「禁用」。名称关键词同时匹配节点标题与类型。`signal` 为透传输入。

#### 面板设置（组控制、节点控制共用）

点击节点底部的「⚙ 设置」按钮打开。

| 项 | 选项 | 说明 |
| --- | --- | --- |
| 关闭方式 | 绕过（默认）、禁用 | 关闭一行时对节点执行的操作 |
| 模式 | 自由（默认）、恒定开启一个、最多一个开启、至少一个开启 | 各开关之间的联动规则 |
| 排序 | 名称（默认）、位置、状态、颜色 | 行排序依据 |
| 反向排序 | 关（默认）、开 | 排序是否逆序 |
| 名称关键词 | 空 | 以 `;` 分隔多个词，命中任一即列出。为空时不列出行，仅显示提示 |
| 颜色筛选 | 无 | 可多选，仅保留所选颜色的对象；节点无自身颜色时继承所属分组颜色 |

画布变更时面板自动刷新（增删节点、改名、改色）。节点宽度可拖动调整，记录于节点属性并随工作流保存。

### 适配尺寸 🐈‍⬛

按宽高比与百万像素算出目标尺寸，再用单一缩放系数把图像放上去，全程不拉伸。选「自适应」时目标比例取自输入图片；目标与图片比例相差 2% 以内则居中裁掉多余部分，相差更大则补黑边。

| 项 | 默认 | 说明 |
| --- | --- | --- |
| 图像 | — | 待适配的图像 |
| 宽高比 | 自适应 | 自适应加 8 种固定比例：1:1、2:3、3:2、3:4、4:3、9:16、16:9、21:9 |
| 百万像素 | 1.0 | 目标总像素，步进 0.01 |
| 倍数 | 32 | 把算出的尺寸取整到该倍数，填 1 保留原始结果 |

节点下方有实时分辨率预览。输出为适配后的图像、实际产出的宽度与高度，以及 `resolution`——与结果像素数相同的正方形边长，1 MP 的正方形结果为 1024。

### 无限画布素材载入

在 `infinite_canvas` 分类下显示为「Infinite Canvas Asset」。用于把画布素材带入工作流。
